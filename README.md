# Sprint_6
Учебный проект по работе написания автотестов для учебного сервиса «Яндекс.Самокат» с применением Page Object Model

## Описание проекта
Данный учебный проект содержит автотесты для тестирования функциональности сайта «Яндекс.Самокат» в браузере **Mozilla Firefox**

Структура проекта построена с применением Page Object Model:
    - Локаторы распределены постранично и находятся в папке locators
    - Методы, необходимые для написания тестовых функций находятся в папке pages и также распределены постранично
    - Все тестовые функции находятся в папке tests

Вспомогательные файлы
    - файл curl.py содержит необходимые url для работы
    - файл data.py содержит необходимый для проверки ответов на вопросы текст
    - в файле helper.py содержатся функции для генерации персональных данных пользователя и начала даты аренды
    - в папке tests создан файл conftest.py с фикстурой для инициализации браузера
